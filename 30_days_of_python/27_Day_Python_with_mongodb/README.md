# Day 27 – Python with MongoDB

This project demonstrates how Python connects to MongoDB using `pymongo`.

## What I practiced
- Connecting to MongoDB Atlas using a URI
- Creating a database + collection
- CRUD operations (insert, find, update, delete)
- Filtering queries (ex: age > 30)
- Sorting + limiting results

## How to run
1. Create a `.env` file with your MongoDB URI:
   MONGODB_URI=your_connection_string_here
2. Install packages:
   pip install -r requirements.txt
3. Run:
   python app.py
