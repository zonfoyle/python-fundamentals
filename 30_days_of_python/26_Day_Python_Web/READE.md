
This project demonstrates the basics of using **Flask**, a lightweight Python web framework,
to build a simple web application with multiple routes and HTML templates.

The goal of this day was to understand how Python is used in web and cloud environments,
not to build a full production application.

---

## 🚀 What This Project Covers

- Creating a Flask application
- Defining routes using decorators
- Rendering HTML templates with Jinja2
- Passing data from Python to HTML
- Using a basic project structure for web apps

---

## 🧠 Why This Matters for Cloud / Solutions Architect Roles

Flask is commonly used to:
- Build internal tools and dashboards
- Create backend APIs
- Serve microservices on AWS (EC2, ECS, Lambda)
- Prototype services quickly before scaling

Understanding Flask helps bridge **Python programming** with **cloud architecture**.
