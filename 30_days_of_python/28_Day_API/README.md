# Day 28 – APIs (Application Programming Interfaces)

This section focuses on understanding and consuming REST APIs using Python.

The goal is not to build a full backend,
but to understand how applications communicate over HTTP.

---

##  What I Learned

- What APIs are and why they matter
- REST API principles
- HTTP request/response cycle
- Common HTTP methods (GET, POST, PUT, DELETE)
- HTTP status codes
- Consuming public APIs using Python

---

##  Why This Matters for Cloud Engineers

APIs are the foundation of cloud systems:
- AWS services are accessed via APIs
- Microservices communicate via APIs
- Automation and monitoring rely on APIs
- Infrastructure-as-Code tools call APIs

Understanding APIs is essential for:
- Cloud Engineers
- Solutions Architects
- Backend Engineers
